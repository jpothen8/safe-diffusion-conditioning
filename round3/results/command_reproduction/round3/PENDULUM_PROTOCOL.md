# Fresh comparison including BayesFP

Freeze the existing trained Pendulum DDPM, 100-step sampler, 12-action/0.6 s chunk, both one-sided constraints and 10 s native return. Use new states and seeds in `configs/pendulum.json`; 64 state clusters, 8 replicates and 64 independent rejection proposals per replicate. All arms execute the same duration and use the same deterministic TD3 continuation. No task reward enters any sampler.

Arms: exact first-feasible rejection; exact full-horizon projection; the already-frozen finite annealed refinement; paper-derived BayesFP with 32 particles, raw and followed by exact final projection; and BayesFP with 12 particles, raw and followed by projection. The 12-particle arm approximately matches refinement's score-evaluation count (1200 versus 1124 including the base sample). This does not force equal wall-clock latency.

BayesFP is a **reimplementation of the published DDPM algorithm**, not official author code or a reproduced author benchmark. Use safety cost J(x)=mean(relu(x)^2) for the negative envelope and mean(relu(-x)^2) for the positive envelope, in normalized torque coordinates. Its cost-weighted posterior at finite strength is softer than hard conditioning. Use strength 20, selected by the smallest average development MMD of repaired outputs to rejection among {1,5,20,100,500}. Repair ensures feasibility in all settings; raw feasibility is still separately reported. The same strength applies to both signs and particle counts. Appendix G.4 fixes the DDPM guidance, FK weights and resampling implementation, recorded in `src/bayesfp.py`.

Primary newly requested comparisons are finite refinement minus BayesFP+projection for each sign and each particle count: four paired native-return differences. Bootstrap 64 state-cluster means with 20,000 resamples; use individual 98.75% intervals to adjust for these four comparisons. A useful refinement advantage requires mean gain >=5 points and interval above zero. A negative interval or inconclusive result is retained. Gains versus original projection use the earlier 25-point practical threshold, reported descriptively with 95% intervals here.

Report all requested outputs, raw unsafe rates, repaired rates, first-accept budgets/refusals, stabilization, added-boundary mass, state-wise acceptance, MMD to the same exact rejection reference, independent q-versus-q discrepancy, wall times, score evaluations, ESS and initial-ancestor diversity. Raw BayesFP returns never count as a safe-policy win when its output is unsafe. Save every base proposal and final particle cloud. No reward-based selection of reference or returned particles; BayesFP selects by its own final particle weights.
