# Safety conditioning versus projection: reproducible simulation experiments

**Latest extension:** [Round 3 results](../../round3/RESULTS.md) add trained Walker2d/HalfCheetah diffusion policies and BayesFP comparisons. [Paper integration](../../round3/PAPER_INTEGRATION.md) and [LaTeX experiments](../../round3/paper_experiments.tex) separate target utility from finite-sampler performance. BayesFP plus projection is competitive on Pendulum; refinement has a promising setting-specific HalfCheetah advantage. Mixed and negative results remain visible.

This fresh project contains the original Push-T pilot and **confirmed useful Pendulum examples**, all executed on the target workstation. Start with [RESULTS.md](../../RESULTS.md), [ROUND2_RESULTS.md](../../ROUND2_RESULTS.md), and [TASK_SELECTION.md](../../TASK_SELECTION.md).

With a trained state diffusion policy, exact conditioning improved native Pendulum return by 54.68 / 47.91 points over exact full-horizon projection in two mirrored torque-envelope examples. The supplied draft's finite annealed-refinement mechanism improved return by 56.31 / 48.66. All adjusted intervals exclude zero; all 3,072 outputs are feasible. Refinement still has a measurable distribution gap from rejection. The weaker/negative Push-T findings and all development settings are retained.

## Reproduce Pendulum

Linux x86_64, Python 3.12, a compiler for Pymunk 6.2.1, and about 8 GB for the environment/assets are needed. The recorded GPU run uses RTX 5070 Ti, driver 595.84, PyTorch 2.7.1+cu128. `rtk` prefixes match the workspace instructions. If launched through a restricted agent sandbox, downloads and GPU runs need host execution; no driver installation or modification is required on the inspected host.

From this directory:

```bash
rtk proxy bash scripts/setup_pendulum.sh
rtk proxy .venv/bin/python scripts/verify_followup.py
rtk proxy .venv/bin/python src/pendulum_audit.py
rtk proxy .venv/bin/python scripts/run_pendulum_replication.py --output-root results/my_pendulum_replication
```

Choose a fresh output root. The replication command copies the locked inputs and saves results at `results/my_pendulum_replication/results/pendulum/confirmation/`. It protects existing directories and does not overwrite the delivered experiment. This command was tested end to end in `results/command_reproduction`.

If the locally trained model is missing, setup acquires the pinned public TD3 actor and trains the modest diffusion policy from complete simulated episodes. To reproduce the collected dataset and training separately without overwriting the frozen model:

```bash
rtk proxy .venv/bin/python scripts/train_pendulum_recorded.py --output-root results/my_training_replication
```

The delivered isolated training rerun reproduced both the demonstration archive and model SHA256 exactly on this workstation. The wrapper explicitly retains original data-collection arithmetic; reported evaluation uses the corrected float64 implementation verified against Gym. Checkpoints, demonstration group splits, training-only normalization, full proposal banks, complete rollouts, hashes, all failures and the precision-correction history are preserved. See `records/followup_assets.json` and `results/pendulum/confirmation/audit.json`.

Useful entry points:

- `src/pendulum.py`: public actor extraction, symmetric controller, exact Gym dynamics and common continuation.
- `src/pendulum_train.py`: state DDPM architecture, 100-step sampler, episode-group split and training.
- `src/pendulum_refine.py`: explicit VP-to-VE score conversion and finite projected Langevin refinement.
- `src/pendulum_confirm.py`: locked proposals, first-feasible reference, exact box projection, outcomes and clustered intervals.
- `src/pendulum_audit.py`: independent selection/projection/provenance checks and correction audit.
- `src/pendulum_figures.py`: PNG/PDF/SVG plots and GIF illustrations, selected without reward ranking.
- `src/pendulum_continuation_check.py`: separately labeled sensitivity to a reflected common continuation controller.
- `configs/pendulum_confirmation.json`, `PENDULUM_CONFIRMATION.md`: seeds, sample sizes, physical times, severity, metrics and decision rules.
- `results/pendulum/confirmation`: corrected primary results; `confirmation_initial_precision`: retained initial failed replay check.

## Reproduce Push-T

```bash
rtk proxy bash scripts/setup.sh
rtk proxy .venv/bin/python src/smoke.py --device cuda --episodes 8
rtk proxy .venv/bin/python src/develop.py
rtk proxy .venv/bin/python src/verify.py
rtk proxy .venv/bin/python src/evaluate.py --output results/replication_01
rtk proxy .venv/bin/python src/analyze.py --input results/replication_01
```

The existing `results/heldout` is protected against accidental rerunning/overwriting by its protocol lock. Use a fresh output directory. `src/audit_results.py` independently audits the delivered `results/heldout` files; its saved audit validates 6,144 proposals, 288 paired requests and 576 safe outputs. Set `MPLCONFIGDIR` to a writable temporary/project directory if desired; the matplotlib cache warning is harmless. No display is opened (`SDL_VIDEODRIVER=dummy`).

The setup script uses the exact dependency lock, checks out the recorded source revision, downloads the checkpoint if missing, verifies its hash and all upstream source hashes, and checks dependency consistency. It does not download unused demonstrations. The experiment imports the upstream simulator and frozen EMA policy directly; vendor source is unchanged. The actual install logs are under `records/`; the setup script consolidates those executed installation steps. CPU smoke is available via `--device cpu`; the delivered development/evaluation drivers intentionally default to CUDA.

## Files

- `src/core.py`: checkpoint loading, observation/action alignment, deterministic reset-and-replay snapshots.
- `src/safety.py`: affine full-horizon speed predicate, convex projection and physics observer.
- `src/smoke.py`, `src/develop.py`, `src/verify.py`: untouched policy smoke, development probe, meaningful dynamics/projection checks.
- `src/evaluate.py`: frozen proposal banks, first-feasible rejection, projection, paired common continuation and failure records.
- `src/analyze.py`, `src/audit_results.py`: state-cluster uncertainty, occupancy/quality plots and independent selection/feasibility audit.
- `configs/pilot.json`: locked horizons, caps, seeds, sample sizes and effect threshold.
- `results/heldout/protocol_lock.json`: protocol/code hashes saved **before** held-out proposals.
- `results/heldout/proposals_*.npz`: all action proposals `[replicate,proposal,control,xy]`, 81 speed values (initial plus 80 substeps), severity membership masks and RNG seeds. The same 6,144 proposals serve all three caps; they are not 18,432 independent proposals.
- `results/heldout/snapshot_*.json`: reset seed, complete warmup action prefix, numeric state and observation history.
- `results/heldout/outcomes_*.json`: every requested pair, rejection/solver records, output actions, reward traces, completion and safety outcomes.
- `results/heldout/traces_*.npz`: actual simulator substeps, columns `[pusher_x,pusher_y,pusher_vx,pusher_vy,block_x,block_y,block_angle]`.
- `records/asset_manifest.json`, `records/vendor_hashes.json`, `records/*sources.json`, `requirements.lock.txt`, `records/dependency_licenses.json`: provenance and dependency records.

All results are simulated. The Pendulum extension trains a small diffusion imitation model and implements a finite projected Langevin sampler from the supplied draft. It does not implement a safe-set estimator or claim a generally correct/efficient conditional sampler. Walker2d and HalfCheetah were subsequently acquired, trained and evaluated in [round3](../../round3/README.md); Humanoid remains researched but unexecuted. No external telemetry service is initialized by the local drivers.
