# Exploratory safe-set mismatch analysis

This follows the user's hypothesis that boundary concentration is particularly harmful when the supplied safe set is slightly inaccurate. It reuses all eight frozen HalfCheetah models and their 64 shared held-out states, four requests/state. It is a retrospective sensitivity analysis, not a new independent confirmation or an evaluation of a learned safe-set estimator.

The existing samplers receive the estimated set C_hat = {A in [-1,1]^48: RMS(A)<=.72}. Keep every existing sample and native rollout unchanged. Define the true cap as .72*(1-error), with relative errors [-.01, 0, .0001, .001, .005, .01, .02, .05]. Positive error means C_hat is optimistic; negative error means it is conservative. Fix this grid before computing the new metrics. It probes a uniform inward boundary error, not every possible bias, orientation error or state-dependent estimation error.

For Q, exact projection P, finite refinement R, raw BayesFP and repaired BayesFP, report true violation frequency, maximum/mean/RMS violation magnitude, estimated versus true margin, all-request native return and state/model variation. Preserve all original outputs, including unsafe and poor outcomes. Do not assign an invented collision penalty to an effort-envelope violation or interpret it as physical damage. Numerical feasibility tolerance remains 1e-6 in normalized RMS/action coordinates; report it separately from the error sizes.

As a bounded simulator control, evaluate projection of the same first base draws onto a fixed 1%-smaller supplied cap (.7128), and first-feasible rejection under that cap using the same saved independent proposal banks. Reuse the same .4 s chunk, 4 s native evaluation and SAC continuation. Save all new outputs and refusal indices. At 1% error this projection is the exact projection onto the true set; it is also the result of a conservative projection filter supplied with an a priori 1% error bound. For smaller/larger errors it respectively over/under-buffers. Distinguish this additional uncertainty assumption from the original arms' input; it is a robustness control, not an unfairly informed primary competitor.

The exact original projection is global Euclidean projection over all 48 chunk coordinates, not an approximate solver or one-step filter. The question here is the correctness of its supplied set. A positive true violation count can coexist with exact projection onto C_hat.

No retuning, new training, reward-based sample selection or replacement states. Report descriptive crossed model/state bootstrap intervals at the fixed 1% error, including the conditioning/projection and refinement/projection violation-rate differences. Do not select the most favorable error after seeing results. Save all errors, source hashes, the new protocol, code and underlying study lock before analysis. Comparison of existing returns under changed safety labels is not a new rollout; only the two conservative controls require new simulation.
